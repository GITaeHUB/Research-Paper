# 📚 Paper Reader

논문 PDF 를 넣고 → **해설**로 큰 그림을 잡고 → **원문·번역**을 문단마다 읽으며 → 궁금한 곳을 **Q&A** 로 묻고 → 로컬 문서와 **Notion** 에 정리하는 개인 도구.

## 설치 (처음 한 번)
- 필요한 것: Windows 10/11 · **Python 3.8+** (외부 패키지 없음) · **VS Code + Claude Code 확장** (로그인되어 있어야 함) · **Git for Windows** (PDF 글 추출용 `pdftotext` 가 들어 있음) · Microsoft Edge 또는 Chrome
- 받기: `git clone https://github.com/GITaeHUB/Research-Paper.git` → 폴더의 `논문리더.cmd` 더블클릭
  → **처음 한 번** 바탕화면에 아이콘이 붙은 **Paper Reader** 바로가기가 자동으로 생깁니다. 그다음부터는 그 바로가기로 여세요.
  (`.cmd` 파일은 자기 아이콘을 가질 수 없어 바로가기로 붙입니다. 지웠다가 다시 만들려면 `python rp.py shortcut`)
- Notion 을 쓰려면 아래 "Notion 연결" 을 따라 `config.local.json` 을 만듭니다 (`config.local.example.json` 참고).
- `papers/` · `library/` · `exports/` · `data/` 는 처음 실행할 때 자동으로 생깁니다. 개인 데이터라 Git 에는 올라가지 않습니다.

## 여는 법
- `논문리더.cmd` 더블클릭 (또는 `python rp.py app`). 주소창 없는 창이 열립니다.
- 창을 닫아도 번역이 진행 중이면 끝까지 마치고 스스로 꺼집니다. 다시 열면 이어서 보입니다.

## 쓰는 순서
1. **PDF 넣기** — `papers/` 폴더에 넣으면 왼쪽 목록에 바로 나타납니다. arXiv 논문은 왼쪽 아래에 링크·번호를 넣어도 됩니다.
2. **읽기 시작** — 논문을 고르고 `읽기 시작` 을 누르면
   분석(제목·저자·학회·번역 단위·용어집) → **해설**과 **번역**이 동시에 진행됩니다. 해설이 먼저 끝나므로 그것부터 읽으세요.
3. **해설 탭** — 한 줄 요약 · 읽기 전 배경 · 풀려는 문제 · 핵심 아이디어 · 방법 흐름(텐서 shape) · 읽기 가이드 · Task 내 위치(연구 흐름) · 관련 중요 논문 · 결과 · 한계.
   관련 논문에는 출처가 붙습니다: `참고문헌 [n]` / `웹 확인` / `미확인`.
4. **원문·번역 탭** — 문단마다 원문(회색) → 번역. `원문 + 번역 / 번역만 / 원문만` 전환. 문단에 마우스를 올리면:
   - `📌 질문` 그 문단을 붙여서 질문 · `💡 깊게 해설` · `🖼 그림 해설` · `∑ 수식 풀이`
   - `✎ 메모` · `p.N` 오른쪽 패널에 PDF 그 쪽 열기
   - **글자를 드래그해서 고르면**: `🖍 하이라이트` (고른 부분만 노랗게, 누르면 지우기) · `📌 이 부분 질문` · `💡 이 부분 해설`
   - 깊게 해설 · 그림 해설 · 수식 풀이 결과는 **그 문단 바로 아래 카드**로 붙고 (Q&A 탭에도), 카드 안의 `삭제` 로 지울 수 있습니다.
5. **Q&A** — 오른쪽 패널에서 질문 (Ctrl+Enter). 답은 **요약 제목 토글**로 쌓이고, 위치 태그(§3.2-4, Fig. 3, Eq. 5, 전체)와 분류 태그가 붙습니다.
   Q&A 탭에서 논문 순서 / 시간순 정렬, 태그 거르기, `본문에서 보기`. 문단 아래 `💬 N` 으로도 펼쳐집니다.
   같은 논문의 질문은 대화가 이어집니다. 끊고 싶으면 `새 대화로`.
   질문 칸 아래에서 **답변 길이**(짧게 / 보통 / 자세히)와 **모델**(깊게 = Opus / 절약 = Sonnet)을 고릅니다.
6. **정리** — `exports/<논문>/` 에 해설.md · 원문·번역.md · Q&A.md 가 자동으로 만들어집니다 (`문서 폴더` 버튼).
   `Notion 에 올리기` 를 누르면 Research Paper 페이지의 Papers 데이터베이스에 올라갑니다.

## 그 밖의 기능
| 어디 | 기능 |
|---|---|
| 그림 `✂ 다시 자르기` | 자동으로 잘린 그림이 틀리면 PDF 쪽 위에서 영역을 직접 끌어서 다시 저장 |
| 화면 테마 | 위쪽 🌓 버튼: 자동(윈도우 설정) → 밝게 → 어둡게 |
| 오른쪽 패널 | 왼쪽 경계를 끌어서 폭 조절, 두 번 누르면 넓게 ↔ 기본 |
| 왼쪽 목록 | 자동으로 깜빡이며 바뀌지 않습니다. 새 PDF 를 넣었으면 `↻ 새로 고침` (작업이 끝나면 저절로 갱신) |
| 그림 · 표 블록 | PDF 에서 그 그림만 잘라 번역 화면에 바로 보여 줌 (한 번 잘라 두면 저장되고 Notion 에도 이미지로 올라감). 누르면 오른쪽에 PDF 그 쪽 |
| 질문 패널 | Claude 가 답을 쓰는 동안 실시간으로 보임 |
| 번역 버튼 | 남은 단위 · 예상 시간 표시. 단위 2개씩 동시에 번역 (`tools/config.py` 의 `TRANSLATE_PARALLEL`) |
| 용어집 탭 | 번역 표기 고치기 (다음 번역부터 적용). ★ = 모든 논문 공용 용어집에도 |
| 메모 탭 | 하이라이트·메모 모아 보기 → 누르면 그 문단으로 |
| 코드 탭 | 공식 GitHub 저장소를 찾아 논문 모듈 ↔ 코드 파일 연결, 읽는 순서 |
| 발표 요약 탭 | 버튼을 누를 때만: 랩미팅용 슬라이드 5~7장 분량 요약 |
| 위 `비교표` | 왼쪽에서 논문 여러 편을 골라 방법·입력·손실·벤치마크·성능 비교 (표마다 `삭제`) |
| 위 `계보도` | 라이브러리 논문들의 Task 별 계보 그래프 + 다음에 읽을 논문 추천. 확대·축소 · 맞춤 · 크게 보기, `삭제` |
| 위 `라이브러리 질문` | 읽은 논문 전체에 질문 ("temporal fusion 다룬 논문들은 각각 어떻게?"), 답마다 `삭제` |
| 위 검색창 | 본문·번역·Q&A·메모·해설 즉시 검색 (Claude 없이) |
| 읽기 상태 | 논문 머리의 `읽을 예정 / 읽는 중 / 완료`, 왼쪽 목록 거르기 |

## Notion 연결 (한 번만, 무료)
1. https://www.notion.so/profile/integrations → **새 통합** (Internal) → 토큰 `ntn_…` 복사
2. Notion 의 **Research Paper** 페이지 → 오른쪽 위 `⋯` → **연결(Connections)** → 방금 만든 통합 추가
3. 이 폴더에 `config.local.json` 만들기 (Git 에 올라가지 않음):
   ```json
   {"notion_token": "ntn_여기에_토큰", "notion_parent": "Research Paper 페이지 링크 끝의 32자리 id"}
   ```
4. 프로그램을 다시 열고 `Notion 에 올리기`.

다시 동기화하면 **바뀐 부분만** 고칩니다 (하위 페이지 링크·댓글 유지, 바뀐 게 없으면 몇 초). Notion 에서 블록을 직접 지워 순서가 꼬이면 그 하위 페이지만 새로 채웁니다.

## 보안
프로그램은 이 컴퓨터(127.0.0.1)에서만 열리고, 켤 때마다 새 비밀 토큰을 만들어 프로그램 창만 데이터에 접근할 수 있게 합니다 (다른 웹페이지가 몰래 요청할 수 없음). Notion 토큰은 `config.local.json` 에만 있고 Git 에 올라가지 않습니다.

## Claude 사용량
- 번역·분석 = Sonnet, 해설·Q&A·비교·계보도 = Opus. (`config.local.json` 의 `"models": {"translate": "opus"}` 처럼 바꿀 수 있음)
- claude.ai 구독으로 로그인해 쓰면 호출마다 돈이 나가지 않고 **구독 사용 한도**에서 차감됩니다.
- 위쪽 `사용량 N%` = 구독 **5시간 한도** 사용률 (Claude 가 응답마다 알려 주는 값, 누르면 주간 한도·초기화 시각).
- 논문 머리와 작업 목록에 **토큰**(입력 / 출력)이 보입니다. 번역 버튼에는 남은 단위 · 예상 시간, 마우스를 올리면 예상 토큰.
- **토큰 절약 장치** (자동):
  - 자동 호출은 Claude Code 기본 시스템 프롬프트 대신 짧은 전용 프롬프트 (호출마다 ~2.3K 토큰 ↓)
  - 번역은 생각(effort)을 낮게, 분석은 보통으로
  - 질문할 때 논문 전체를 먼저 읽지 않고 Grep 으로 필요한 곳만 찾아 읽음
  - 같은 논문의 대화가 길어지면 (입력 120K 토큰 넘음) 다음 질문은 앞 대화 대신 지난 Q&A 요약만 들고 새 대화로
  - 간단한 질문은 `절약`(Sonnet) + `짧게` 로: 예) 깊게 해설 1회 입력 ~20K · 12초
- 대략: 분석 1회 입력 ~40K · 번역 단위당 입력 ~30K / 출력 ~4K · 질문 하나 입력 50~150K (논문을 다시 읽는 양에 따라). 기록: `data/claude_log.jsonl`

## 명령줄 (`python rp.py ...`)
| 명령 | 하는 일 |
|---|---|
| `list` / `scan` | 논문 목록 / 새 PDF 등록 |
| `analyze <key>` · `overview <key>` · `translate <key> [--unit 3 4]` | 분석 · 해설 · 번역 (지정 단위 다시) |
| `ask <key> "질문" [--anchor 3.2-4] [--kind explain]` | 질문 |
| `slides <key>` · `code <key>` | 발표 요약 · 코드 연결 |
| `export [<key>]` · `notion <key>` | 마크다운 다시 만들기 · Notion 동기화 |
| `usage [<key>]` · `serve` · `app` | 사용량 · 서버만 · 창 열기 |

## 폴더
`papers/` PDF · `library/` 논문별 데이터 (원본) · `exports/` 읽는 문서 (자동 생성) · `data/` 전체 데이터 · `tools/` 파이썬 · `web/` 화면 — 자세한 구조는 `CLAUDE.md`.

## 시작하기

| 단계 | 할 일 |
|:---:|---|
| **1** | 저장소를 받습니다 — `git clone https://github.com/GITaeHUB/Research-Paper.git` |
| **2** | 폴더 안의 **`논문리더.cmd`** 를 더블클릭합니다. 처음 한 번 바탕화면에 아이콘이 붙은 **Paper Reader** 바로가기가 생기고, 그다음부터는 그 바로가기로 엽니다. |
| **3** | 읽을 논문 PDF 를 **`papers/`** 폴더에 넣거나, 왼쪽 아래 칸에 arXiv 링크·번호를 넣습니다. |
| **4** | 논문을 고르고 **읽기 시작** 을 누릅니다. |

> **필요한 것** — Python 3.8 이상 · VS Code 의 **Claude Code** 확장 (로그인되어 있어야 함) · **Git for Windows** (PDF 글자를 뽑는 `pdftotext` 가 들어 있음) · Microsoft Edge 또는 Chrome

## 읽는 흐름

```
 PDF 넣기  →  읽기 시작  →  해설 먼저 읽기  →  원문·번역 읽으며 질문  →  Notion 에 올리기
              (분석 1~3분,     (2~4분이면 완성)    (번역은 뒤에서 계속 진행)
               해설·번역 동시 시작)
```

### 해설 — 번역을 읽기 전에
한 줄 요약 · 읽기 전에 알아야 할 배경 · 풀려는 문제 · 핵심 아이디어 · 방법 흐름(텐서 shape 포함) · 꼭 읽을 곳과 건너뛸 곳 · 이 Task 안에서의 위치와 연구 흐름 · 관련 중요 논문 · 결과 · 한계.
관련 논문에는 출처가 붙습니다 — `참고문헌 [n]` / `웹 확인` / `미확인`. 위쪽 **다시 만들기** 로 새로 만들 수 있습니다.

### 원문 · 번역
문단마다 원문(회색 상자) 아래에 번역. `원문 + 번역` / `번역만` / `원문만` 을 바꿔 볼 수 있습니다.

- 그림 · 표는 PDF 에서 그 부분만 잘라서 보여 줍니다. 잘못 잘렸으면 **다시 자르기** 로 직접 고릅니다.
- 문단에 마우스를 올리면 카드 위쪽 가장자리에 **질문 · 깊게 해설 · 메모 · PDF 쪽** 버튼이 뜹니다 (글을 가리지 않음). 그림에는 그림 해설, 수식에는 수식 풀이.
- **글자를 드래그하면** **하이라이트 · 이 부분 질문 · 이 부분 해설** 을 고를 수 있습니다. 하이라이트를 누르면 지워집니다.
- 깊게 해설 결과는 그 문단 바로 아래 카드로 붙고, 제목 줄의 **삭제** 로 언제든 지울 수 있습니다.

### Q&A
오른쪽 패널에서 질문합니다 (Ctrl+Enter). 답은 Claude 가 쓰는 대로 실시간으로 보이고, 끝나면 **요약 제목이 붙은 토글**로 쌓입니다.

- 질문마다 **답변 길이** (짧게 / 보통 / 자세히) 와 **모델** (깊게 = Opus / 절약 = Sonnet) 을 고릅니다.
- 위치 태그(§3.2-4, Fig. 3, Eq. 5, 전체)와 분류 태그가 붙고, Q&A 탭에서 논문 순서 / 시간순으로 볼 수 있습니다.
- 같은 논문의 질문은 대화가 이어집니다. 끊고 싶으면 **새 대화로**.

## 기능 한눈에

| 어디 | 기능 |
|---|---|
| 용어집 탭 | 번역에서 쓸 용어 표기를 고칩니다 (다음 번역부터 적용). ★ 를 켜면 모든 논문 공용 용어집에도 |
| 메모 탭 | 하이라이트와 메모를 모아 보고, 누르면 그 문단으로 이동 |
| 코드 탭 | 공식 GitHub 저장소를 찾아 논문의 모듈과 코드 파일을 연결하고, 읽는 순서를 알려 줌 |
| 발표 요약 탭 | 버튼을 누를 때만 — 랩미팅용 슬라이드 5~7장 분량 요약 |
| 위 **비교표** | 왼쪽에서 논문 여러 편을 골라 방법 · 입력 · 손실 · 벤치마크 · 성능 비교 |
| 위 **계보도** | 라이브러리 논문들의 Task 별 계보 그래프와 다음에 읽을 논문 추천 (확대 · 맞춤 · 크게 보기) |
| 위 **라이브러리 질문** | 읽은 논문 전체에 묻기 — "temporal fusion 을 다룬 논문들은 각각 어떻게 하지?" |
| 위 검색창 | 본문 · 번역 · Q&A · 메모 · 해설을 바로 검색 (Claude 를 쓰지 않음) |
| 위 **사용량 N%** | Claude 구독의 5시간 한도 사용률. 누르면 주간 한도와 초기화 시각 |
| 화면 | 오른쪽 패널 폭은 경계를 끌어서 조절 · 테마 버튼으로 자동 / 밝게 / 어둡게 |

비교표 · 계보도 · 라이브러리 질문 · Q&A · 해설 카드는 모두 지울 수 있습니다.

## 정리 문서와 Notion

- 모든 내용은 `exports/<논문>/` 에 마크다운으로 자동 저장됩니다 — `해설.md` · `원문·번역.md` · `Q&A.md` (논문 머리의 **문서 폴더** 버튼).
- **Notion 에 올리기** 를 누르면 Notion 의 Papers 데이터베이스에 논문 한 편이 한 행으로 들어가고, 그 안에 해설 / 원문·번역 / Q&A 하위 페이지가 생깁니다.
  다시 올리면 **바뀐 부분만** 고칩니다 (링크와 댓글은 그대로).

<details>
<summary><b>Notion 연결하기</b> (한 번만, 무료)</summary>

1. https://www.notion.so/profile/integrations 에서 **새 통합**(Internal)을 만들고 토큰 `ntn_…` 을 복사합니다.
2. Notion 에서 정리할 페이지를 열고 오른쪽 위 `⋯` → **연결(Connections)** → 방금 만든 통합을 추가합니다.
3. 이 폴더에 `config.local.json` 을 만듭니다 (Git 에 올라가지 않음, 예시는 `config.local.example.json`):
   ```json
   {"notion_token": "ntn_여기에_토큰", "notion_parent": "그 페이지 링크 끝의 32자리 id"}
   ```
4. 프로그램을 다시 열고 **Notion 에 올리기**.

Notion API 는 무료이고 Claude 사용량도 들지 않습니다.
</details>

## Claude 사용량

번역 · 분석은 **Sonnet**, 해설 · Q&A · 비교 · 계보도는 **Opus** 를 씁니다. claude.ai 구독으로 로그인해 쓰면 호출마다 돈이 나가지 않고 **구독 사용 한도**에서 차감됩니다.
논문 머리와 작업 목록에 토큰 수가, 위쪽에 한도 사용률이 보입니다.

토큰을 아끼는 장치가 기본으로 켜져 있습니다.

- 자동 호출에는 짧은 전용 시스템 프롬프트를 씁니다 (호출마다 약 2.3K 토큰 절약).
- 번역은 생각하는 양을 낮게 둡니다.
- 질문할 때 논문 전체를 먼저 읽지 않고 필요한 곳만 찾아 읽습니다.
- 같은 논문의 대화가 길어지면(입력 12만 토큰 넘음) 앞 대화 대신 지난 Q&A 요약만 들고 새 대화로 넘어갑니다.
- 간단한 질문은 **절약 + 짧게** 로 — 예: 깊게 해설 한 번에 입력 약 2만 토큰, 12초.

| 작업 | 대략 |
|---|---|
| 분석 | 입력 ~40K |
| 번역 (단위 하나) | 입력 ~30K · 출력 ~4K. 30쪽 논문은 25~30단위, 2개씩 동시에 진행 |
| 해설 | 입력 ~50K (한 번) |
| 질문 하나 | 절약 ~20K · 깊게 50~150K |

모델 · 동시 번역 수 · 세션 한도는 `config.local.json` 에서 바꿀 수 있습니다 (예: `{"models": {"translate": "opus"}}`).

## 보안과 개인 데이터

- 프로그램은 **실행한 그 컴퓨터 안에서만** 열립니다 (`127.0.0.1`). 같은 와이파이의 다른 기기나 인터넷에서는 접속할 수 없습니다.
- 켤 때마다 새 비밀 토큰을 만들어 프로그램 창만 데이터에 접근하게 합니다. 같은 컴퓨터에서 열린 다른 웹페이지도 몰래 요청할 수 없습니다.
- 논문 PDF · 번역 · Q&A · 메모(`papers/` `library/` `exports/` `data/`)와 Notion 토큰(`config.local.json`)은 **Git 에 올라가지 않습니다.**

## 폴더

```
papers/      논문 PDF (직접 넣음)
library/     논문별 데이터 — 번역 · 해설 · Q&A · 메모 · 잘라 둔 그림
exports/     읽는 문서 (자동 생성)
data/        용어집 · 비교표 · 계보도 · 사용 기록
tools/       파이썬 (서버 · Claude 호출 · 번역 · Notion …)
web/         화면
```

자세한 구조와 번역 · 답변 규칙은 [`CLAUDE.md`](CLAUDE.md), 개발 기록은 [`PLAN.md`](PLAN.md).
